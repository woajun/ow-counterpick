# 오버워치 카운터픽

적 팀 조합을 고르면 유리한 스왑 후보와 피해야 할 픽을 보여 주는 도구.
게임 중에 알트탭으로 넘어와서 몇 초 안에 쓰는 것을 전제로 만들었다 —
로그인이 없고, 홈 화면에서 바로 고르고 바로 초기화된다.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
npm run preview
```

## 상성 데이터 고치는 곳

`src/data/matchups.ts` 하나다. 영웅 하나가 적으로 나왔을 때 내 쪽에서

- `good` — 확실한 카운터 (+3)
- `ok` — 나쁘지 않은 선택 (+1)
- `bad` — 그 적을 상대로 고생하는 픽 (−3)

점수는 적 하나하나가 독립적으로 얹는 단순한 합이다. 시너지나 맵은 안 본다.
설명할 수 없는 가중치를 넣는 것보다, 왜 그 픽이 올라왔는지를 근거 칩으로
그대로 보여주는 쪽이 게임 중에 쓸모 있다고 봤다.

값은 커뮤니티에서 통용되는 관계를 정리한 것이라 밸런스 패치마다 달라진다.
절대적인 기준이 아니라 스왑 후보를 좁히는 용도로 쓴다.

영웅을 추가하려면 `src/data/heroes.ts` 에 넣고 `matchups.ts` 에도 항목을
적어야 한다. 상성을 안 적으면 타입 검사에서 걸린다 — 목록에는 뜨는데 추천에는
영영 안 나오는 영웅이 생기는 것을 막는다.

## 구조

| 파일 | 하는 일 |
| --- | --- |
| `src/data/heroes.ts` | 영웅 명단과 역할 |
| `src/data/matchups.ts` | 상성표 |
| `src/lib/score.ts` | 적 조합 → 영웅별 점수와 근거 |
| `src/lib/useTeam.ts` | 적 팀 상태, 5v5·6v6, localStorage |
| `src/components/` | 상단 바 · 적 슬롯 · 영웅 목록 · 추천 |

## 정해 둔 것

**어두운 화면 한 벌만 쓴다.** 게임에서 넘어오는데 밝은 페이지가 뜨면 눈이
부셔서 도구로 못 쓴다. 라이트 테마는 안 만든다.

**처음 열면 예시 조합이 깔려 있다.** 빈 껍데기는 무엇을 하는 도구인지
안 보여 준다. 손대는 순간 예시 표시가 내려가고, 예시 자체는 저장하지 않는다.

**단축키** — <kbd>/</kbd> 검색, 검색창에서 <kbd>Enter</kbd> 첫 결과 추가,
<kbd>Backspace</kbd> 마지막 적 제거, <kbd>Esc</kbd> 검색 비우기.
